# 🔍 Wikipedia & arXiv Research Paper Search Engine

An AI-powered research assistant built with Python, Streamlit, LangChain, and Groq. It allows users to search Wikipedia, find research papers on arXiv, and generate AI-powered explanations of research topics and papers.

## 🚀 Features

### 1. Wikipedia Search
- Search for machine learning and other technical topics.
- Retrieve relevant information from Wikipedia.
- Generate AI-powered explanations using a Groq LLM.
- View the search results through a simple Streamlit interface.

### 2. arXiv Paper ID Search
- Search for research papers using an arXiv paper ID.
- Retrieve paper titles, authors, abstracts, and publication details.
- Access available research paper links.
- Generate AI-powered explanations of research papers.

### 3. arXiv Topic Search
- Search for research papers using keywords or topics.
- Retrieve relevant research papers from arXiv.
- Explore paper abstracts and publication information.
- Use AI to understand research findings more easily.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Streamlit** – Interactive web application
- **LangChain** – LLM integration and agent tools
- **Groq** – Large language model inference
- **Requests** – HTTP requests to external APIs
- **Wikipedia** – Knowledge retrieval
- **arXiv API** – Research paper retrieval
- **Python-dotenv** – Environment variable management
