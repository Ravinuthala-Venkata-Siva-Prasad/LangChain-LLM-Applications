# LangChain LLM Applications 🚀

A collection of Generative AI applications built using Python, LangChain, and Streamlit. This repository demonstrates the integration of Large Language Models (LLMs), chatbot development, and Retrieval-Augmented Generation (RAG).

## 📌 Projects

### 1. Ollama Chatbot
An interactive chatbot built using LangChain, Streamlit, and Ollama.

**Features:**
- Integration with locally hosted LLMs.
- Support for selecting available language models.
- Interactive user interface using Streamlit.
- Configurable model settings.

**Technologies:** Python, LangChain, Streamlit, Ollama.

[View Project](./Ollama-Chatbot/)

### 2. OpenAI Chatbot
An interactive chatbot that uses OpenAI language models through LangChain.

**Features:**
- Integration with OpenAI models.
- Interactive Streamlit interface.
- Model selection and configurable settings.
- LangSmith tracking configuration.

**Technologies:** Python, LangChain, Streamlit, OpenAI API, LangSmith.

[View Project](./OpenAI-Chatbot/)

### 3. RAG Document Q&A Chatbot 📚
An AI-powered application that allows users to upload PDF research papers and ask questions about their content.

**Features:**
- Upload multiple PDF documents.
- Extract and split document text.
- Generate embeddings using Hugging Face.
- Store and retrieve embeddings using FAISS.
- Generate answers using a Groq-hosted language model.
- Display relevant document sections and source information.

**Technologies:** Python, LangChain, Streamlit, Hugging Face, FAISS, Groq, PyPDF.

[View Project](./RAG-Document-Q&A/)
